🛍️ BUYLY — Multi-Vendor Marketplace

BUYLY is a modern multi-vendor marketplace designed to make online shopping simple, customizable, and convenient. Customers can explore products from independent shops, choose product variants, save favorites, customize eligible products with a live preview, place orders through Cash on Delivery, and track their orders.

The platform also gives vendors their own dashboard where they can manage products, view incoming orders, review customer and customization details, and update order fulfilment status.

🔐 Data & Marketplace Architecture

BUYLY is designed with a customer-facing storefront and a separate vendor management experience.

The application includes backend API routes for:

Products

Orders

Vendors

Customer customization uploads

Vendor product uploads

Persistent marketplace data can be connected through Supabase, while the storefront also includes a built-in catalog fallback so the shopping experience can continue when persistent database configuration is unavailable.

🚀 Deployment

BUYLY can be deployed on Vercel.

Basic deployment flow

Upload/push the project to GitHub.

Import the repository into Vercel.

Configure the required environment variables.

Connect the Supabase project/database.

Deploy the application.

Open the generated Vercel URL.

For production marketplace functionality, the required Supabase/database configuration and server-side keys should be added to the deployment environment.

🎯 Project Goal

The goal of BUYLY is to create a practical and modern marketplace where multiple vendors can sell products while customers get a simple, flexible, and personalized shopping experience.

From discovering products to customizing an item, placing a Cash on Delivery order, and tracking fulfilment, BUYLY brings the complete shopping journey into one platform.
